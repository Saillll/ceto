# Ceto · 东北冬泳基地水温检测系统

> 面向东北户外冬泳基地的低成本水温监测系统：**实时测温 · 现场墨水屏显示 · 4G 上报 · 小程序查看**。

## 项目定位

- **场景**：东北冬泳基地，气温低至 -30℃，水温 0~8℃，棚内/户外。
- **核心价值**：以实时监测替代人工测温，数据可追溯、可扫码查看。
- **差异化**：轻量化、百元级硬件、可多点部署、可复制。

## 系统架构

```
设备端（岸上机箱，电池供电）
  Air780EGH（4G Cat.1 + GPS）
   ├─ DS18B20 防水探头(5m)  → 水温
   ├─ SHT31                 → 气温 / 湿度
   ├─ 2.9" 墨水屏(SSD1680)  → 常亮显示 水温/气温/湿度/时间
   ├─ 18650（带保护板）+ 充电口
   ├─ 4G 天线
   └─ 有源 GPS 天线(5m，引到棚外)
        │
        │ MQTT/TLS，5 分钟上报
        ▼
腾讯云 IoT Explorer（设备接入/规则引擎）
        ▼
微信云开发 CloudBase（云数据库 + 云函数，免域名）
        ▼
微信小程序（个人主体）：扫码即看 / 实时曲线 / 历史 / 后台统计
```

## 关键决策（已确认）

| 项 | 决定 |
|---|---|
| 主控 | **Air780EGH**（4G Cat.1 + GPS） |
| 上报 | 5 分钟，MQTT/TLS，长连接，低功耗模式 |
| 供电 | 18650（带保护板）+ 充电口（现场充，不拆电池） |
| 显示 | 2.9" 墨水屏 SSD1680，常亮，变化时局部刷新 |
| 定位 | GPS，开机 1 次 + 每天 1 次 |
| 传感器 | 水温 DS18B20 + 气温湿度 SHT31（水质暂不做） |
| 云 | 腾讯云（IoT Explorer + 微信云开发） |
| 部署 | Serverless + SaaS，**不用虚机** |
| 小程序 | **个人主体**，扫码即看 + openid 统计 |
| 告警 | 无主动推送（用户扫码主动看） |
| 配置 | 电脑上用 Luatools 手动配置（ID/名字/云参数） |
| 地图 | 腾讯位置服务（地名逆地理编码） |
| 规模/预算 | 1 台试点 / <1000 元/年 |
