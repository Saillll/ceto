# 12 · 部署自动化与参数

> 目标：说清楚"哪些能自动化、哪些必须你手动、你需要提供什么参数"。

---

## 一、三类部署

| 对象 | 部署方式 | 谁执行 |
|---|---|---|
| **设备固件** | Luatools 烧录（USB） | 你（本地） |
| **云资源**（IoT/数据库/云函数） | 手动控制台 **或** Terraform/API | 你 或 我写脚本你跑 |
| **小程序** | 微信开发者工具 或 `miniprogram-ci` | 你 |

---

## 二、云资源：Terraform 方案（推荐）

**Terraform** = 用代码声明式创建云资源（可重复、可版本管理）。

- Provider：`tencentcloudstack/tencentcloud`
- 可管理：IoT 产品/设备、云开发环境、COS、CAM 等
- 参考：`https://registry.terraform.io/providers/tencentcloudstack/tencentcloud/latest/docs`

**本仓库将提供**（待补）：
```
infra/
├── main.tf          # provider + 资源
├── variables.tf     # 参数（secret_id/secret_key/region...）
└── terraform.tfvars # 你的实际值（.gitignore，别提交！）
```

**流程**：
1. 你提供 **SecretId / SecretKey / region** 等参数。
2. 我把参数写进 `terraform.tfvars`（**不提交到仓库**）。
3. 你本地执行 `terraform init && terraform apply`（或我通过命令执行）。
4. 创建完，把生成的 ProductId/DeviceName/DeviceSecret 回填到 `firmware/config.lua`。

> ⚠️ **密钥安全**：SecretKey / AppSecret 是敏感信息，**只放本地**，别提交仓库。

---

## 三、小程序：CI 上传方案

- 工具：`miniprogram-ci`（npm 包，微信官方）
- 需要：**AppID** + **上传密钥（CI 私钥）** + 项目配置
- 流程：
  1. 你提供 AppID + 上传密钥文件。
  2. 我把配置写进 `miniprogram/` 项目。
  3. 执行 `miniprogram-ci upload` 上传代码 → 后台提交审核 → 发布。

> 参考：`https://developers.weixin.qq.com/miniprogram/dev/devtools/ci.html`

---

## 四、我能做到 / 不能做到

| 事项 | 能否 |
|---|---|
| 写 Terraform / 部署脚本 / CI 配置 | ✅ 能 |
| 写小程序代码 + 云函数 | ✅ 能 |
| 提交代码到 GitHub | ✅ 能（用 Contents API） |
| **替你登录腾讯云/微信控制台** | ❌ 不能（需你的账号/密钥） |
| **替你实名认证** | ❌ 不能 |
| **替你点"发布"** | ❌ 不能（需你账号授权；CI 上传后仍需你审核发布） |

**结论**：我负责**写脚本 + 写代码**；**执行部署**需要你的**密钥/授权**（你提供参数，我生成脚本，你或我在有权限的环境执行）。

## 五、需要你提供的参数清单

### 腾讯云
| 参数 | 从哪来 |
|---|---|
| SecretId / SecretKey | 控制台 → 访问管理 → API 密钥 |
| region | 如 `ap-guangzhou` |
| （可选）已有 IoT 产品 ID | 控制台 |

### 微信
| 参数 | 从哪来 |
|---|---|
| AppID | mp 后台 → 开发 → 开发设置 |
| AppSecret | 同上 |
| 上传密钥（CI 私钥） | mp 后台 → 开发 → 小程序代码上传 |

### 云开发
| 参数 | 从哪来 |
|---|---|
| 环境 ID（envId） | 云开发控制台 |

---

## 六、部署顺序建议

1. **本地**：烧录固件跑通（不依赖云）。
2. **腾讯云**：建 IoT 产品/设备 → 拿三元组。
3. **回填** `firmware/config.lua` → 重新烧录 → 设备上报成功。
4. **云开发**：建库/云函数。
5. **规则引擎**：设备数据 → 数据库。
6. **小程序**：开发 → 上传 → 审核 → 发布。
