# 07 · 开发板与模组选型

## 一、合宙 Air780 系列定位

- **Air780 系列** = 4G Cat.1 **低功耗** SoC 模组，主打"低功耗 + 纯物联网"。
- **Air724UG** = 老一代"功能全"型号（支持 VoLTE/TTS/音频/摄像头/屏），现不主推。
- **需要语音/屏/摄像头** → 老 Air724；**低功耗远传** → Air780（本项目选它）。

## 三、官方功耗（Air780 系列）

| 模式 | API | 4G状态 | 典型功耗 |
|---|---|---|---|
| 常规 | `pm.power(pm.WORK_MODE, 0)` | 在线长连接 | 较低（7~8mA） |
| 低功耗 | `pm.power(pm.WORK_MODE, 1)` | 在线长连接 | 均衡（1.5~2mA） |
| PSM+ | `pm.power(pm.WORK_MODE, 3)` | 离线飞行 | 极低（3~12µA） |

测试条件：3.8V，心跳 5 分钟，TCP，合宙服务器。

## 四、固件类型说明

| 固件 | 角色 | 要不要外部 MCU | 开发方式 |
|---|---|---|---|
| **AT 固件** | 通信模组 | 要 | MCU 发 AT 指令 |
| **DTU 固件(iRTU)** | 透传网关 | 不要 | 网页配置，免开发 |
| **LuatOS 二开** | SoC 主控 | 不要 | **写 Lua 代码** |

**本项目选 LuatOS 二次开发**（自己写代码）。

## 五、贴片卡 vs 插拔卡

- **插拔卡**（原型用）：普通 4G 流量卡/手机卡，个人可买。
- **贴片卡**（量产用）：13 位卡号，需**企业实名**；合宙 Air780 的 **SIM2 通道专为贴片卡设计**（官方 SIM 设计文档）。
- **闲鱼贴片卡风险**：来源不明、随时可能失效，**正式产品勿用**。
- 能读出：**ICCID / IMSI**；读不到：手机号（物联卡无）、套餐/余额/实名。
