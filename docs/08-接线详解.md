## 二、接线示意

```
                  ┌─────────────────────────────┐
   4G天线 ──IPEX──┤ LTE_ANT                     │
  GPS天线 ──IPEX──┤ GNSS_ANT        Air780EGH    │
                  │                核心板        │
   ┌── 3.3V ──────┤ 3.3V                        │
   │              │  I2C_SDA ────── SDA (SHT31)  │
   │              │  I2C_SCL ────── SCL          │
   │              │                             │
 [DS18B20] DQ ────┤ GPIO ──┬─ 4.7kΩ ── 3.3V     │
   │              │        └─ DQ                │
   │              │                             │
 [墨水屏]          │  SPI_CLK/MOSI/CS ─ CLK/DIN/CS│
   │              │  GPIO ×3 ───────── DC/RST/BUSY│
   │              │                             │
 [18650] ─+───────┤ VBAT                        │
   │     ─────────┤ GND                         │
 [TP4056] ────────┤ VBAT/GND（充电口）          │
                  └─────────────────────────────┘
```

## 三、电源

- **18650 带保护板**（过充/过放/过流/短路）→ 直连 **VBAT**（3.3~4.3V）。
- **TP4056（1A）** + 充电口 → **现场用充电宝充，不拆电池**（避免断电丢时间）。

## 四、注意事项

1. **DS18B20 必须加 4.7kΩ 上拉**。
2. **GPS 有源天线**接 IPEX，且**引到棚外/无遮挡处**。
3. 墨水屏选 **SSD1680**，确认 LuatOS 有对应 demo。
4. 河边户外：天线/线缆**防雷防护**。
5. 开**看门狗**。
6. 外壳：防水接线盒 + 线缆出入口密封；探头线缆固定。
