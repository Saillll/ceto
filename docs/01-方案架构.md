# 01 · 方案架构

## 一、需求确认（最终版）

| 项 | 决定 |
|---|---|
| 场景 | 东北冬泳基地，水温 + 岸上气温/湿度/时间，墨水屏现场显示 |
| 供电 | **纯电池（18650，带保护板）**，无市电；现场用充电口充电 |
| 屏幕 | **2.9" 墨水屏**，常亮，显示 水温/气温/湿度/时间 |
| 传感器 | **水温 DS18B20 + 气温湿度 SHT31**；**水质暂不做** |
| 上报 | **5 分钟，MQTT/TLS，长连接，低功耗模式** |
| 定位 | **GPS**（开机 1 次 + 每天 1 次） |
| 告警 | **无主动推送**（用户扫码主动看） |
| 小程序 | **个人主体**，扫码即看 + **openid 统计** |
| 云 | **腾讯云**（IoT Explorer + 微信云开发） |
| 部署 | **Serverless + SaaS，不用虚机** |
| 规模/预算 | 1 台试点 / <1000 元/年 |

## 二、系统架构

```
┌─────────────────────────────────────────────────────────┐
│  设备端（岸上机箱，电池供电）                              │
│  Air780EGH 核心板（4G Cat.1 + GPS）                        │
│   ├─ DS18B20 防水探头（5m）→ 水温                          │
│   ├─ SHT31 → 气温/湿度                                    │
│   ├─ 墨水屏 2.9"(SPI) → 常亮显示 水温/气温/湿度/时间        │
│   ├─ 18650（带保护板）+ 充电口                             │
│   ├─ 4G 天线                                              │
│   └─ 有源 GPS 天线（5m，引到棚外）                         │
└───────────────────────┬─────────────────────────────────┘
                        │ MQTT/TLS，5 分钟上报
                        │ 数据：水温 + 气温 + 湿度 + 电量 + GPS + ICCID + ID
                        ▼
        ┌───────────────────────────────┐
        │  腾讯云 IoT Explorer（设备接入）│  ← 三元组鉴权
        │        规则引擎                │
        └───────────────┬───────────────┘
                        ▼
        ┌───────────────────────────────┐
        │  微信云开发（CloudBase）        │
        │   ├─ 云数据库（存温度记录）      │
        │   └─ 云函数（HTTPS API，免域名）│
        └───────────────┬───────────────┘
                        ▲
                        │ 扫码进入 → wx.login → openid
        ┌───────────────┴───────────────┐
        │  微信小程序（个人主体）          │
        │  扫码即看 / 实时曲线 / 历史      │
        │  地图(腾讯位置服务) / 后台统计    │
        └───────────────────────────────┘
```

## 三、设备上报数据格式

```json
{
  "dev_id":   "ceto-001",
  "dev_name": "SY-Changqing",
  "iccid":    "8986xxxxxxxxxxxxxx",
  "water_temp": 3.5,
  "air_temp":   -20.1,
  "humidity":   45.2,
  "battery":    85,
  "lat":        43.9123,
  "lng":        128.7654,
  "ts":         1730000000
}
```

| 字段 | 说明 |
|---|---|
| `dev_id` | 自定义设备 ID（如 `ceto-001`） |
| `dev_name` | 自定义名字（`SY`=城市，`Changqing`=基地名） |
| `iccid` | 贴片卡/流量卡卡号（`mobile.iccid()`） |
| `water_temp` | 水温（DS18B20） |
| `air_temp` | 气温（SHT31） |
| `humidity` | 湿度（SHT31） |
| `battery` | 电量（`adc.CH_VBAT` 电压换算） |
| `lat` / `lng` | GPS 经纬度（开机 + 每天一次） |
| `ts` | 时间戳（NTP 对时，北京时间 UTC+8） |

## 四、断网处理

- **策略**：**断网重试**（断网后定时重连，恢复后继续正常上报）。
- **不补数据**（用户明确不要断点续传）。
- **纯软件实现**，不加硬件。

## 五、FOTA 远程升级

- **纯软件**（LuatOS `libfota`/`fota` 库）+ 升级服务器。
- 升级服务器**不一定是虚机**：优先用**合宙免费 FOTA**，或**对象存储 + 云函数**。
- 注意：下载固件**耗流量**（几 MB）。

## 六、开发/调试方式

- **USB 数据线 + 电脑 + Luatools**：烧录、看日志、调试。
- **联网走 4G**（Air780 无 WiFi）。
- 现场升级：**4G FOTA**（远程）或**带电脑 USB 烧录**；"板子连手机热点"不可行（无 WiFi）。
