## 二、要不要焊接？—— 先说清楚

**焊接 = 用高温把焊锡熔化，把金属脚和电路板焊在一起**（永久连接）。
**松香/助焊剂** = 帮助焊锡更好附着、防止氧化的"药水"，不是必需品但更好焊。

### 本项目的焊接需求

| 部位 | 要焊吗 | 说明 |
|---|---|---|
| **核心板排针** | ⚠️ 可能要 | 若买的**已焊排针**版 → 不用焊；若**光板** → 要自己焊排针 |
| **DS18B20 探头线** | ❌ 不用 | 探头自带三根线，用杜邦线/端子接 |
| **SHT31 / 墨水屏 / 天线** | ❌ 不用 | 都是模块，用杜邦线插接 |
| **电池 ↔ TP4056 ↔ 板子** | ⚠️ 可能 | 可用**弹簧端子**免焊；或焊线更牢 |

**结论**：**买"已焊排针的核心板" + 弹簧端子 + 杜邦线 → 可以几乎不焊接**。
**不会焊怎么办**：① 买已焊排针版；② 让卖家代焊；③ 找手机维修店代焊（几块钱）。

### 焊接前提（如果你要焊）
1. **工具**：电烙铁 + 焊锡丝（含松香）+ 助焊剂/松香 + 斜口钳。
2. **注意**：电烙铁很烫（300~400℃），别烫手/烫线；焊完检查有没有**连锡**（两个脚被锡连一起）。
3. **上拉电阻**：DS18B20 的 4.7kΩ 电阻可以**焊在杜邦线上**，或焊在板子上（后文有说明）。

### 4.7kΩ 上拉电阻怎么接（编号 4/5）
```
   3V3 ──[4.7kΩ]──┐
                  ├── 接 DS18B20 黄线(DQ, 编号3)
   DS18B20 黄线 ───┘
```
即：电阻一端接 3V3，另一端和 DS18B20 数据线接在一起。

## 四、接线步骤（按编号）

1. **先断电**（不插电池、不插 USB）。
2. 按编号 **1~17** 接传感器和屏（杜邦线插接）。
3. 接**编号 18~21**（电池→TP4056→核心板 VBAT/GND）。**注意正负极别接反！**
4. 接**编号 22/23**（两根天线，IPEX 座轻轻按入）。
5. 检查所有接线，**确认没有接反/短路**。
6. 先**只插 USB**（不插电池）→ 看核心板是否上电/亮灯。
7. 插电池 → 拔 USB → 看是否仍供电。

## 五、上电检查

- 用**万用表**测：3V3 对 GND 应约 **3.3V**；VBAT 对 GND 应约 **3.7~4.2V**。
- 若发烫/冒烟 → **立即断电**，检查正负极和短路。
