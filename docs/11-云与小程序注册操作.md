# 11 · 云与小程序注册操作

> 目标：注册腾讯云、创建 IoT 设备、注册微信小程序、把数据打通。
> ⚠️ 腾讯云/微信的产品与界面会更新，**具体以官方控制台当前为准**。

---

## 一、腾讯云账号

1. 打开 `https://cloud.tencent.com/` → **注册**（微信/邮箱/手机）。
2. **实名认证**（个人即可，用于物联网/云开发）。
3. 登录**控制台**。

## 二、创建 IoT 设备（设备接入）

> 腾讯云有两个相关产品，二选一：
> - **物联网通信（IoT Hub）**：`cloud.tencent.com/document/product/634`
> - **物联网开发平台（IoT Explorer）**：`cloud.tencent.com/document/product/643`
> 本文按 **MQTT 接入** 描述（两者都支持 MQTT）。

步骤：
1. 进入 IoT 控制台 → **创建产品**（如"冬泳水温监测"）。
2. 在产品下**创建设备**（如 `ceto-001`）。
3. 记录设备的 **三元组**：
   - **ProductId**（产品 ID）
   - **DeviceName**（设备名）
   - **DeviceSecret**（设备密钥）
4. **接入地址**（MQTT）：`${ProductId}.iotcloud.tencentdevices.com`
   - 端口：MQTT 非加密 `1883` / TLS `8883`
5. **Topic 规则**（默认）：
   - 上报：`${ProductId}/${DeviceName}/event`
   - 订阅：`${ProductId}/${DeviceName}/control`
   - 收发：`${ProductId}/${DeviceName}/data`
6. 用三元组按官方算法生成 **MQTT 的 username/password**（官方有"设备接入"文档与计算工具）。

> 官方参考：`https://cloud.tencent.com/document/product/634/11907`（开发者手册/设备接入协议）

## 三、把数据存起来

1. **规则引擎/数据流转**：把设备上报的数据转发到**云开发数据库**或**消息队列**。
2. 或用**云函数**接收并写库。

## 四、微信云开发（后端，免服务器）

1. 打开 `https://cloud.tencent.com/product/tcb`（云开发 CloudBase）。
2. 开通**云开发环境**（有免费额度）。
3. 建**数据库集合**：`devices`、`records`、`visits`（统计）。
4. 建**云函数**：`login`（换 openid）、`query`（查数据）、`stats`（统计）。
5. 云开发提供**默认域名**，小程序直连，**免自建域名/备案**。

> 官方参考：`https://docs.cloudbase.net/`

## 五、微信小程序注册

1. 打开 `https://mp.weixin.qq.com/` → **注册** → 选择**小程序**。
2. 主体选 **个人**（免费；功能受限，无主动告警推送）。
3. 填**邮箱、密码**，邮箱验证。
4. 登录后：**完善信息**（名称、头像、简介、**服务类目**）。
5. **获取 AppID**（开发设置里），后续代码要用。

> 官方参考：`https://developers.weixin.qq.com/miniprogram/introduction/`

## 六、小程序备案（上线必须）

1. 2023-09 起，小程序**必须完成 ICP 备案**才能发布。
2. 在 mp 后台 → **设置 → 基本设置 → 小程序备案**，按指引提交。
3. 个人主体可备案，但**服务类目受限**。

## 七、小程序开发与发布

1. 装**微信开发者工具**，用 AppID 新建项目。
2. 开发页面：扫码即看 / 曲线 / 历史 / 地图 / 统计。
3. 关联**云开发环境**（开发者工具里一键关联）。
4. **提交审核** → 通过后**发布**。
5. 在后台**生成小程序码**（贴设备/海报）。

## 八、扫码与统计（关键说明）

- 用户扫码 → 进入小程序 → 小程序调 `wx.login` 拿 `code` → 后端 `code2session` 换 **openid**（**静默、无需授权**）。
- **默认只能拿 openid**；手机号/昵称需用户授权（手机号还要企业主体）。
- 本方案：**只拿 openid**，做匿名统计（访问量、扫码人数、设备查看次数）。

## 九、部署方式：手动 or 自动化？

| 方式 | 说明 | 是否可行 |
|---|---|---|
| **手动**（控制台点点点） | 在腾讯云/微信控制台手动创建资源、上传云函数 | ✅ 最直观 |
| **API/SDK** | 用腾讯云 SDK 创建资源 | ✅ 可行 |
| **Terraform** | 用 `tencentcloud` provider 声明式创建 | ✅ 可行（见 docs/12） |
| **微信小程序代码上传** | 用**微信开发者工具的"上传"**，或 `miniprogram-ci` CLI | ✅ 可行 |

> **结论**：设备侧固件用 Luatools 烧录；云资源可手动或 TF；小程序用开发者工具上传或 `miniprogram-ci`。

## 十、需要你提供的参数（我才能自动化部署）

| 参数 | 从哪来 |
|---|---|
| 腾讯云 **SecretId / SecretKey** | 腾讯云控制台 → 访问管理 → API 密钥 |
| 腾讯云 **地域(region)** | 如 `ap-guangzhou` |
| IoT **ProductId / DeviceName / DeviceSecret** | 创建产品/设备后 |
| 云开发**环境 ID** | 云开发控制台 |
| 微信小程序 **AppID / AppSecret** | mp 后台 → 开发设置 |
| （小程序上传）**CI 私钥** | 微信公众平台 → 开发 → 上传密钥 |
