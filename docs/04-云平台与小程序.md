# 04 · 云平台与小程序

## 一、云厂商对比（腾讯云 vs 阿里云）

| 维度 | 腾讯云 | 阿里云 |
|---|---|---|
| 设备接入 | IoT Explorer（MQTT） | IoT 平台（MQTT，公共实例免费） |
| 小程序后端 | ⭐ **微信云开发**：免服务器、免域名备案、有免费额度 | 要自建 FC/ECS + 域名 + 备案 |
| 微信生态 | ⭐ 同生态，最顺 | 一般 |
| 成本(1 台试点) | ~¥0/月 | ~¥0/月 |
| 适合 | ⭐ **推荐** | 规模大时 |

**选择：腾讯云**（微信云开发 + IoT Explorer）。

## 二、云资源清单

| 资源 | 用途 | 费用 |
|---|---|---|
| **腾讯云 IoT Explorer** | 设备 MQTT 接入、三元组鉴权、规则引擎 | 免费额度 |
| **微信云开发 CloudBase** | 云数据库 + 云函数 + 免域名 HTTPS | 免费额度 |
| 域名/服务器 | **不需要**（云开发默认域名） | ¥0 |
| **合计** | — | **≈¥0/月（试点期）** |

## 三、部署方式：Serverless + SaaS（不用虚机）

| 环节 | 传统做法（要虚机） | 本方案（免虚机） |
|---|---|---|
| 设备接入 | 自建 MQTT(EMQX) | **IoT Explorer（SaaS）** |
| 数据存储 | 自建 MySQL | **云开发数据库（SaaS）** |
| 后端逻辑 | 自建服务+运维 | **云函数（Serverless）** |
| 域名/HTTPS | 买域名+备案+证书 | **云开发默认域名，免备案** |

**结论**：**不需要买虚机（ECS/CVM）**。

## 四、FOTA 升级服务器

| 方案 | 要不要虚机 |
|---|---|
| **合宙免费 FOTA（推荐）** | ❌ 不用 |
| 对象存储(OSS/COS) + 云函数 | ❌ 不用 |
| 自建 HTTP 服务器 | ✅ 可虚机 |

**选择：先用合宙免费 FOTA**。

## 五、微信小程序（个人主体）

| 项 | 说明 |
|---|---|
| 注册 | mp.weixin.qq.com，**个人主体**（免费） |
| 备案 | 小程序 ICP 备案（个人可备案） |
| 扫码 | 生成**小程序码**，贴设备/海报 |
| 获取信息 | **仅 openid**（`wx.login` 静默获取，无需授权） |
| 后台统计 | 访问 PV/UV、扫码人（openid 去重）、设备查看次数、活跃时段 |
| **不能做** | ❌ 主动告警推送（个人主体无长期订阅） |

### 扫码获取信息说明

- **默认只能拿 `openid`**（通过 `wx.login` → code → 后端 `code2session` 换 openid），**静默、无需授权**。
- **手机号/昵称头像**：需用户主动授权，且**手机号需企业主体**（个人拿不到）。
- 本方案：**只拿 openid**，做匿名统计。

## 七、地图地名

- **方案**：设备名固定（`SY-Changqing`）+ 小程序用**腾讯位置服务**逆地理编码显示实际地名。
- 腾讯位置服务与微信同生态，免费额度够用。

## 八、腾讯云接入简述

1. 腾讯云控制台创建 **IoT Explorer 产品 + 设备**，拿 **三元组（ProductKey/DeviceName/DeviceSecret）**。
2. 代码里填入三元组 → 设备 MQTT 接入。
3. 配置**规则引擎**：设备数据 → 云开发数据库。
4. 云函数提供 HTTPS API（登录、查询、统计）。
5. 小程序调用云函数展示。
