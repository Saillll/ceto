# 10 · 软件安装与开发操作

> 目标：把电脑、开发板、代码打通，能烧录、能看日志、能联网。

---

## 一、需要安装的软件

| 软件 | 用途 | 获取 | 平台 |
|---|---|---|---|
| **Luatools** | 烧录固件 + 看调试日志（核心工具） | 合宙官网/文档站下载 | Windows |
| **USB 驱动** | 电脑识别开发板 | 合宙文档站 | Windows |
| **VSCode + LuatOS 插件**（可选） | 写代码 | 官网 | Win/Mac |
| **微信开发者工具** | 开发小程序 | 微信官方 | Win/Mac |

> 官方参考：
> - Luatools 教程：`https://docs.openluat.com/common/Luatools/`
> - USB 驱动：`https://docs.openluat.com/common/usb_drv/`
> - 烧录故障排查：`https://docs.openluat.com/common/howtodown/`
> - Air780 快速上手：`https://docs.openluat.com/air780epm/luatos/quick_start/`

## 二、环境搭建步骤

1. **装 USB 驱动**：按官方说明安装，插上开发板后电脑"设备管理器"能看到串口/端口。
2. **装 Luatools**：解压/安装（一般免安装）。
3. **（可选）装 VSCode + LuatOS 插件**：搜索 "luatos" 安装。
4. **准备一张 4G 手机卡**（测试用，注意尺寸 Nano/Micro）插入核心板卡座。
5. **接 4G 天线**。

## 三、烧录流程（Luatools）

1. USB 线连接**开发板 ↔ 电脑**。
2. 打开 **Luatools** → 选择正确的**串口/端口**。
3. 选择**固件**：下载对应 Air780EGH 的 **LuatOS 固件**（32/64 位按官方说明）。
4. 选择**项目脚本目录**：指向本仓库的 `firmware/`（内含 `main.lua`）。
5. 点击**下载/烧录**，等待完成。
6. 烧录后开发板自动重启运行。

> 固件与脚本：**先烧固件（底层），再烧脚本（main.lua 等）**。具体以 Luatools 界面为准。

## 四、看日志调试

- Luatools 有"日志/串口"窗口，能看到 `log.info` 打印。
- 代码里用 `log.info("ceto", "...")` 输出调试信息。
- 常见问题：
  - 不认串口 → 装 USB 驱动
  - 烧录失败 → 见官方"固件烧录故障排查"

## 五、代码结构（本仓库 `firmware/`）

```
firmware/
├── main.lua            # 入口：初始化 + 主循环（5分钟）
├── config.lua          # 设备ID/名字/引脚/云参数（烧录前改）
├── drivers/
│   ├── ds18b20.lua     # 水温
│   ├── sht31.lua       # 气温湿度
│   ├── battery.lua     # 电量
│   ├── eink.lua        # 2.9" 墨水屏
│   └── gnss.lua        # GPS
└── net/
    ├── mqtt_client.lua # MQTT/TLS + 断网重连
    └── ntp.lua         # NTP 对时
```

## 六、改配置（`config.lua`）

按**接线编号**（见 `docs/09`）填写：

| 配置项 | 填什么 |
|---|---|
| `dev_id` | `ceto-001` |
| `dev_name` | `SY-Changqing` |
| `pin_ds18b20` | 编号3 用的 GPIO |
| `pin_i2c_sda` / `pin_i2c_scl` | 编号8/9 用的 GPIO |
| `eink.pin_cs/dc/rst/busy` | 编号14~17 用的 GPIO |
| `mqtt.*` | 腾讯云三元组算出的接入参数（见 `docs/11`） |

## 七、分步验证（建议顺序）

1. **只烧"点灯/打印"** → 确认能烧录、能看日志。
2. **接 DS18B20** → 打印水温。
3. **接 SHT31** → 打印气温湿度。
4. **接墨水屏** → 显示固定文字。
5. **插卡 + 天线** → 联网、NTP 对时。
6. **填 MQTT 参数** → 上报到腾讯云。
7. **GPS** → 定位打印经纬度。
8. **低功耗** → 测电流。
