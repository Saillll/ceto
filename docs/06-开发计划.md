## 二、设备端固件（LuatOS，模块划分）

| 模块 | 用到的库 | 说明 |
|---|---|---|
| 读水温 | `onewire` | DS18B20 |
| 读气温湿度 | `i2c` | SHT31 |
| 读电量 | `adc`（`adc.CH_VBAT`） | 电池电压→百分比 |
| GPS 定位 | `libgnss` / `exgnss` | 开机 + 每天一次 |
| 驱动墨水屏 | `eink` / `epd`（SSD1680） | 水温/气温/湿度/时间 |
| 联网 | `socket` / `mqtt` | MQTT/TLS |
| 低功耗 | `pm` | `pm.power(pm.WORK_MODE, 1)` |
| 定时 5 分钟 | `sys` / `rtc` | 周期上报 |
| 看门狗 | `wdt` | 防卡死 |
| NTP 对时 | `socket`（NTP） | 北京时间 UTC+8 |
| FOTA | `libfota` | 远程升级 |
| 设备信息 | `mobile`（`iccid`/`imsi`） | 设备标识 |
| 日志 | `log` | 调试 |

## 五、风险与注意

| 风险 | 应对 |
|---|---|
| GPS 在大棚内被遮挡 | 天线引到棚外；可加 LBS 兜底 |
| 极寒电池衰减 | 电池保温；或改 30 分钟 + PSM+ |
| 墨水屏低温刷新慢 | 选耐低温型号 |
| 设备被外人破坏/偷 | EGG 带 G-sensor 可检测移动（可选升级） |
| 程序卡死 | 开看门狗 |
| 弱网 | 断网重连（不补数据） |
| 户外防雷 | 天线/线缆加防护 |
